\section{Phase 1 Data Report}

This report provides a comprehensive data collection and preprocessing report for two monolingual Transformer language models:

\begin{itemize}
    \item \textbf{Model H (Telugu)}: Higher-resource Indian language
    \item \textbf{Model L (Bhojpuri)}: Lower-resource Indian language
\end{itemize}

\subsection{Data Collection Summary}

\subsubsection{Telugu (Model H)}
\begin{itemize}
    \item Total lines collected: 25,349,199
    \item Estimated tokens: 4,421,917,647 (4.4B)
    \item Web-scraped texts: 29,206 (89.7\% pass rate from 32,549 raw)
    \item Manual corpus: 21,458,261 lines (te.txt)
    \item OCR augmentation: 3,766,703 lines
    \item Target: 500M tokens | Progress: 884.4\%
\end{itemize}

\subsubsection{Bhojpuri (Model L)}
\begin{itemize}
    \item Total lines collected: 1,826,713 (2.3x increase from Phase 1)
    \item Estimated tokens: 291,685,379 (291.7M)
    \item Web-scraped texts: 3,234 (97.2\% pass rate from 3,327 raw)
    \item HuggingFace Corpus: ~261K lines primary source
    \item OCR augmentation: 511,599 lines (28.0%)
    \item Hindi→Bhojpuri Translation (NLLB-200): 15,852 lines
    \item English→Bhojpuri Translation (fineweb-edu): 711,138 lines (39.0%)
    \item Target: 500M tokens | Progress: 58.3\%
\end{itemize}

\subsection{Data Processing Pipeline}

\subsubsection{Cleaning Process}
\begin{itemize}
    \item Unicode NFD normalization
    \item Citation and control character removal
    \item Character whitelisting and script validation
    \item Length/quality filtering (minimum 40 chars, 5+ words, 5\% space density)
    \item MD5-based deduplication
\end{itemize}

\subsubsection{Data Splits (80/10/10)}
\begin{itemize}
    \item Deterministic splitting with seed 42 for reproducibility
    \item No mid-line splits - whole-line preservation
    \item Telugu: 20.3M train / 2.5M val / 2.5M test
    \item Bhojpuri: 621.8K train / 77.4K val / 77.7K test
\end{itemize}

\section{Data Cleaning Pipeline}

\subsection{7-Stage Cleaning Process}

All data undergoes a rigorous 7-stage cleaning pipeline:

\begin{enumerate}
    \item \textbf{Unicode Normalization}: Convert to NFD (Canonical Decomposition)
    \item \textbf{Citation Removal}: Remove Wikipedia citations and references
    \item \textbf{Control Character Removal}: Strip non-printable characters
    \item \textbf{Character Whitelisting}: Retain only valid Unicode ranges
    \item \textbf{Script Validation}: Language-specific script filtering
    \item \textbf{Length/Quality Filters}: Minimum length, word count, density checks
    \item \textbf{Deduplication}: MD5-based exact duplicate removal
\end{enumerate}

\section{Challenges \& Solutions}

\subsection{Challenge 1: Bhojpuri Data Scarcity}

\begin{itemize}
    \item \textbf{Problem}: Bhojpuri is lower-resource with limited text available
    \item \textbf{Solution}: Multi-source strategy
    \begin{enumerate}
        \item Primary: HuggingFace Corpus (386K docs)
        \item Augmentation 1: OCR extraction from Hindi texts
        \item Augmentation 2: Machine translation (Hindi→Bhojpuri)
        \item Augmentation 3: Wikipedia dumps + web scraping
    \end{enumerate}
    \item \textbf{Result}: 776.8K lines collected (sufficient for Phase 2-3)
\end{itemize}

\subsection{Challenge 2: OCR Quality}

\begin{itemize}
    \item \textbf{Problem}: Archive.org OCR'd text contains errors and artifacts
    \item \textbf{Solution}: Aggressive cleaning pipeline with density filters
    \item \textbf{Result}: 97.2\% pass rate even on noisy OCR data
\end{itemize}

\subsection{Challenge 3: Scale Management}

\begin{itemize}
    \item \textbf{Problem}: Telugu manual corpus is 15GB (21.5M lines)
    \item \textbf{Solution}: Order-preserved streaming splits to avoid loading entire file
    \item \textbf{Result}: Memory-efficient processing on standard hardware
\end{itemize}
