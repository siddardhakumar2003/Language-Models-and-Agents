TEMPERATURES REQUIREMENT (From PDF Page 8)
================================================================================

"For each model, generate continuations from held-out prefixes using greedy
 decoding and temperatures 0.5, 1.0, and 1.5. Against reference continuations
 from the held-out set (or teacher-forced targets), report:
 - BLEU (corpus-level; state n-gram order)
 - chrF or chrF++
 - ROUGE-L"

Temperature Interpretation:
  τ = 0.5   → logits / 0.5 (amplified) → more confident, less varied
  τ = 1.0   → logits / 1.0 (default)   → balanced exploration vs. greed
  τ = 1.5   → logits / 1.5 (smoothed)  → more exploratory, higher entropy
